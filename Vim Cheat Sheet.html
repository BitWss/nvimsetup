Neovim & Colemak-DH Cheat Sheet Personalized Vimium Ready

Tailored for Colemak-DH (neio), LazyVim, C++23 Toolchain, and Vimium Browser Parity.

Global & Whole-File Power Combos Essential

  • :%y+ - Copy (yank) entire file to Windows system clipboard
  • ggVG - Select entire file visually from first to last line
  • ggyG - Yank (copy) entire file into default register
  • :%d - Delete (clear) all contents in current buffer
  • ggdG - Alternative: delete everything from line 1 to end
  • gg=G - Auto-indent & reformat entire file indentation
  • <leader> + cf / <leader> + f - Format file with clang-format (4 spaces)
  • :%s/old/new/g - Find and replace all occurrences in whole file
  • :%s/old/new/gc - Replace all with interactive confirmation prompt
  • :g/^$/d - Delete all empty / blank lines across the file
  • :g/pattern/d - Delete all lines containing 'pattern'
  • :v/pattern/d - Invert: delete all lines that DO NOT contain 'pattern'
  • :sort - Sort all lines alphabetically
  • :sort u - Sort lines and remove duplicates
  • :sort n - Sort lines numerically
  • :%to$ - Duplicate entire buffer contents to bottom of file
Pro-Tip: :%y+ is the cleanest way to copy all code to send on Discord or submit on Codeforces. Neovim also syncs y directly to Windows clipboard.

Creating Files & Buffers Tabs & Files

  • :e filename.cpp - Create or open file in current window
  • :vsp filename.cpp - Create / open file in a vertical split
  • :sp filename.cpp - Create / open file in a horizontal split
  • <leader> + fn - LazyVim shortcut to create a new blank buffer
  • <leader> + bn or ]b - Switch to NEXT open tab / buffer
  • <leader> + bp or [b - Switch to PREVIOUS open tab / buffer
  • <leader> + bd - Close / delete tab without closing window split!
  • <leader> + bb - Toggle back to the other / last used buffer
  • <leader> + , or <leader> + fb - Fuzzy search list of all open buffers
  • <leader> + <space> or <leader> + ff - Find and open project files
  • <leader> + w - Save buffer to disk (:w)
  • <leader> + q - Quit Neovim (:q)
Creating from Explorer: Open sidebar (<leader> + e), navigate to directory, and press a to add file.

Vim Tab Pages Layout Tabs

  • gt or :tabnext - Go to NEXT tab page
  • gT or :tabprev - Go to PREVIOUS tab page
  • 2gt - Jump directly to tab page 2 (replace 2 with any #)
  • <leader><tab><tab> or :tabnew - Open a brand new tab page
  • <leader><tab>d or :tabclose - Close current tab page
  • <leader><tab>l - Jump to last tab page
  • <leader><tab>f - Jump to first tab page
  • :tabmove +1 / :tabmove -1 - Move tab right / left
Note: Top bar files in LazyVim are buffers. Use <leader>+bn/bp for buffers and gt/gT for multi-window tabpages.

Window Splits & Switching Colemak-DH

  • Ctrl + w + n - Move focus to split on LEFT
  • Ctrl + w + e - Move focus to split BELOW
  • Ctrl + w + i - Move focus to split ABOVE
  • Ctrl + w + o - Move focus to split on RIGHT
  • Ctrl + w + w - Cycle to next split window
  • Ctrl + w + p - Jump to PREVIOUS accessed split (toggle back & forth)
  • <leader> + wv - Split window vertically
  • <leader> + ws - Split window horizontally
  • <leader> + wd or :close - Close current split
  • Ctrl + w + o or :only - Maximize split: close all other splits
  • Ctrl + w + = - Equalize width and height of all splits
  • Ctrl + w + _ / Ctrl + w + | - Maximize split height / width
  • Ctrl + \ Ctrl + n - Exit terminal mode into normal mode
Terminal Tip: When inside cf-runner's split terminal, press Ctrl+\ Ctrl+n then Ctrl+w i to jump straight back to your code.

Cursor Movement Colemak-DH

  • n - Move left (replaces h)
  • e - Move down / wrapped line (replaces j)
  • i - Move up / wrapped line (replaces k)
  • o - Move right (replaces l)
  • k - Jump forward to end of word (replaces e)
  • K - Jump forward to end of WORD (replaces E)
  • w / W - Jump forward to start of word / WORD
  • b / B - Jump backward to start of word / WORD
  • 0 / ^ / $ - Jump to start / first non-blank / end of line
  • gg / G - Jump to first / last line of document
  • 5G or 5gg - Jump to line number 5
  • % - Jump to matching bracket: (), {}, []
  • fx / tx - Jump to next 'x' / before next 'x'
  • Fx / Tx - Jump backward to 'x' / after previous 'x'
  • ; / , - Repeat previous f/t motion forward / backward
  • } / { - Jump to next / previous code paragraph
  • Ctrl + d / Ctrl + u - Scroll down / up 1/2 page
  • zz / zt / zb - Center / top / bottom screen on cursor
Home-Row: Right hand rests on n (left), e (down), i (up), o (right). Prefix with numbers (e.g. 10e jumps down 10 lines).

Insert Mode & Line Creation Colemak-DH

  • u - Insert before cursor (matches QWERTY 'i' key position)
  • U - Insert at start of line (replaces I)
  • a / A - Append after cursor / at end of line
  • l - Open new line BELOW and insert (replaces o)
  • L - Open new line ABOVE and insert (replaces O)
  • h / H - Insert mode / insert at beginning (aliases)
  • Esc or Ctrl + c - Exit insert mode to normal mode
  • Ctrl + w - Delete word backward in insert mode
  • Ctrl + u - Delete to start of line in insert mode
  • Ctrl + h - Backspace character in insert mode
  • Ctrl + t / Ctrl + d - Indent / de-indent current line
  • Tab - Accept / cycle autocomplete suggestion (super-tab)
  • Enter - Normal newline without accepting popup

Editing, Undo & Redo Colemak-DH

  • z - Undo last change (same physical key on Colemak & QWERTY)
  • Z or Ctrl + r - Redo change
  • . - Repeat last editing command
  • r / R - Replace single character / enter replace mode
  • cc or S - Change (delete & insert) entire line
  • c$ or C - Change from cursor to end of line
  • cuw / ciw - Change inner word
  • cw - Change to end of word
  • s - Flash jump search / substitute character
  • J / gJ - Join line below with / without space
  • ~ - Toggle uppercase ↔ lowercase of single character
  • Ctrl + a / Ctrl + x - Increment / decrement number under cursor

Text Objects & Delimiters Colemak-DH

  • u - Inner text object modifier (u = inner, a = around)
  • cuw / duw / yuw - Change / delete / yank inner word
  • caw / daw / yaw - Change / delete / yank word + surrounding space
  • cu" / du" / yu" - Inside double quotes: "..."
  • cu' / du' / yu' - Inside single quotes: '...'
  • cu( or cub - Inside parentheses: (...)
  • cu{ or cuB - Inside curly braces: {...}
  • cu[ / cu< - Inside square brackets [...] or tags <...>
  • ca( / ca{ / ca" - Change whole block INCLUDING quotes / brackets
  • v / V / Ctrl + v - Characterwise / linewise / block visual mode
  • U or h - Insert in visual block mode
  • > / < - Indent / unindent selected block
  • gv - Re-select last visual selection

Cut, Copy & Registers

  • yy / 2yy - Yank (copy) current line / 2 lines
  • yuw / yiw - Yank inner word
  • y$ or Y - Yank to end of line
  • p / P - Paste after / before cursor
  • dd / 2dd - Delete (cut) current line / 2 lines
  • duw / diw - Delete inner word
  • d$ or D - Delete to end of line
  • x - Delete character under cursor
  • "0p - Paste LAST YANKED text (ignores subsequent deletes!)
  • "_d / "_c - Black-hole register: delete without overwriting clipboard
  • "+y / "+p - Explicit Windows system clipboard yank / paste
  • :reg - Show all register contents
  • qa ... q - Record macro into register 'a'
  • @a / @@ - Play macro 'a' / replay last macro
Clipboard Savior: If you copy something, then delete a word with d, use "0p to paste what you copied instead of what you deleted!

Search, Jumps & Navigation Colemak-DH

  • /pattern / ?pattern - Search forward / backward
  • j - Next search match (replaces n)
  • J - Previous search match (replaces N)
  • <leader> + ch or :noh - Clear search highlights
  • * / # - Search forward / backward for exact word under cursor
  • Ctrl + o - Jump backward in jump list (go back to previous location)
  • Ctrl + i - Jump forward in jump list
  • g; / g, - Jump to previous / next change location in file
  • ma - Set mark 'a' at current position
  • `a / 'a - Jump to exact mark position / line
  • <leader> + / - Search in current file
  • <leader> + fg - Live grep search across entire project

Neo-tree File Explorer Colemak-DH

  • <leader> + e - Toggle file explorer sidebar
  • e / i - Move cursor down / up
  • n - Collapse folder / jump to parent directory
  • o or Enter - Open file / expand folder
  • a - Add new file (end with / to create directory)
  • d - Delete file or directory
  • r - Rename file or directory
  • c / x / p - Copy / cut / paste file
  • H - Toggle hidden dotfiles
  • I - Show file info and permissions
  • q - Close file explorer sidebar

C & C++ Development (LSP) Clangd

  • gh or <leader> + k - Hover documentation for symbol
  • gd - Go to definition
  • gD - Go to declaration
  • gi - Go to implementation
  • gr - Find all symbol references
  • <leader> + cr or <leader> + rn - Rename symbol project-wide
  • <leader> + ca - Code Action (quick fix, auto-import header)
  • <leader> + cf - Format file with clang-format (4 spaces)
  • <leader> + c<Tab> - Switch between source & header (.cpp ↔ .h)
  • [d / ]d - Jump to previous / next diagnostic error
  • <leader> + cd - Show floating diagnostic error message
  • <leader> + xx - Open Trouble diagnostic list
  • <leader> + cs - Document symbol outline

Build, Run & Competitive Programming C++23

  • F6 or <leader> + cc - Compile (C++23) & run with cf-runner in split terminal
  • F6 in Insert mode - Auto-exits insert mode and runs compiler
  • cp or cp1 - Competitive programming template (lines 1-3)
  • <leader> + m - Run :make using project Makefile
  • <leader> + db - Toggle breakpoint (CodeLLDB)
  • <leader> + dc - Start / continue debugger
  • <leader> + di / <leader> + dO / <leader> + do - Step into / over / out
  • <leader> + du - Toggle DAP debugger UI
  • <leader> + dt - Terminate debug session
Autocomplete: Standard library functions automatically insert std:: (e.g. std::abs, std::sqrt). Inlay hints are permanently disabled.

Code Folding & Quick Views

  • zc - Close fold under cursor
  • zo - Open fold under cursor
  • zR - Open ALL folds across whole file
  • zM - Close ALL folds across whole file
  • zj / zk - Move to start of next / previous fold
  • [c / ]c - Jump to previous / next Git diff change

Vimium Browser Extension Browser Parity

  • j / J - Find NEXT / PREVIOUS match (matches Neovim!)
  • I - Enter insert mode (pass keys through to web page)

  • l / L - Vomnibar: Open URL/Search in current / new tab
  • b / B - Open Bookmarks in current / new tab
  • gt or ]b - Switch to NEXT browser tab
  • gT or [b - Switch to PREVIOUS browser tab

Vimium Setup Instructions: Open Vimium Options → paste the configuration below into Custom key mappings → click Save Changes (Ctrl+Enter). 
# ==============================================================================
# Vimium Options - Custom Key Mappings (Colemak-DH Parity)
# ==============================================================================

unmapAll

# 1. Navigation: neio home-row cluster (Left, Down, Up, Right)
map n scrollLeft
map e scrollDown
map i scrollUp
map o scrollRight

# 2. Half-page and full scrolling
map <c-d> scrollPageDown
map <c-u> scrollPageUp
map d scrollPageDown
map u scrollPageUp
map gg scrollToTop
map G scrollToBottom

# 3. Search: j = next match, J = previous match (matches Neovim Colemak)
map / enterFindMode
map j performFind
map J performBackwardsFind

# 4. Open URL / Vomnibar: 'l' replaces 'o' (matches Neovim 'l' line open)
map l Vomnibar.activate
map L Vomnibar.activateInNewTab
map b Vomnibar.activateBookmarks
map B Vomnibar.activateBookmarksInNewTab

# 5. Browser Tabs: gt / gT and ]b / [b match Neovim buffer & tab navigation
map gt nextTab
map gT previousTab
map ]b nextTab
map [b previousTab
map t createTab
map x removeTab
map X restoreTab
map T Vomnibar.activateTabSelection
map yt duplicateTab

# 6. Link hints, history & utilities
map f LinkHints.activateMode
map F LinkHints.activateModeToOpenInNewTab
map yf LinkHints.activateModeToCopyLinkUrl
map yy copyCurrentUrl
map r reload
map R reload hard
map gi focusInput
map H goBack

# 7. Insert mode: Shift-I (so pressing single-key 'i' only moves up)
map I enterInsertMode
map <a-i> enterInsertMode
map <a-q> passNextKey
Colemak Link Hints Tip: Under Advanced Options → Characters used for link hints in Vimium, set: arstdhneio so link shortcuts stay on your Colemak home keys!
