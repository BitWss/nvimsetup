MODULE 01: HORIZONTAL WORD & CHARACTER PRECISION
================================================================================
Goal: Stop pressing 'o' (right) or 'n' (left) ten times in a row. Teleport directly
to where your eyes are looking.

Motions:
  w       : Jump forward to start of next word (punctuation breaks words)
  b       : Jump backward to start of previous word
  k  [e]  : Jump forward to END of current/next word
  W       : Jump forward to start of next WORD (space-delimited only! Ignores next symbols!)
  B       : Jump backward to start of previous WORD
  K  [E]  : Jump forward to END of current/next WORD
  f{char} : Find {char} forward on the current line (cursor lands ON {char})
  F{char} : Find {char} backward on the current line
  t{char} : "Till" {char} forward (cursor lands ONE character BEFORE {char})
  T{char} : "Till" {char} backward
  ;       : Repeat last f/F/t/T search in same direction (SUPER USEFUL!)
  ,       : Repeat last f/F/t/T search in opposite direction

MODULE 03: VERTICAL NAVIGATION SPEED
================================================================================
Goal: Never hold down `e` (down) or `i` (up) to scroll across 50 lines.

Motions:
  gg        : Jump to the very first line of the file
  G         : Jump to the very last line of the file
  {number}G : Jump to exact line number (e.g. 45G) | Or type :45<CR>
  Ctrl-d    : Scroll down half a screen (keeps cursor centered; fast scanning)
  Ctrl-u    : Scroll up half a screen
  {         : Jump backward to previous empty line / paragraph
  }         : Jump forward to next empty line / paragraph (BLAZING fast in code!)
  gzz  [zz] : Redraw screen so the current line is in the exact CENTER of your screen
  gzt  [zt] : Redraw screen so the current line is at the TOP of your screen
  gzb  [zb] : Redraw screen so the current line is at the BOTTOM of your screen

  IMPORTANT COLEMAK-DH NOTE:
  In standard QWERTY Vim, screen centering is `zz`, `zt`, `zb`.
  HOWEVER, in your Colemak-DH layout, `z` is dedicated to UNDO (`z` = undo, `Z` = redo).
  Because pressing `z` once immediately triggers an undo without waiting for combos,
  screen centering is mapped to `gzz` (center), `gzt` (top), and `gzb` (bottom).
  All three commands are 3 keystrokes, eliminating prefix ambiguity so `gzz` triggers instantly!

MODULE 04: THE GRAMMAR OF DELETION
================================================================================
Vim is a language. The core formula is:
  [OPERATOR] + [COUNT] + [MOTION]
Where operator `d` means Delete (and copy into register).

Commands:
  x       : Delete single character under cursor
  dw      : Delete from cursor to start of next word
  dW      : Delete to start of next space-delimited WORD
  dk [de] : Delete from cursor to END of current word
  dd      : Delete entire line
  3dd     : Delete 3 lines
  d$ / D  : Delete from cursor to end of line
  d0      : Delete from cursor backward to start of line (col 0)
  d^      : Delete from cursor backward to first non-blank character
  df{c}   : Delete everything from cursor through {c} inclusive
  dt{c}   : Delete everything from cursor up until {c} exclusive
  d%      : Delete everything between matching brackets

MODULE 05: THE SUPERIORITY OF CHANGE (c) OVER DELETE (d)
================================================================================
KEY INSIGHT: When fixing code, almost NEVER use `dw` followed by entering insert mode.
Always use `c` (Change)!
Why?
1. `c` deletes the target AND immediately puts you into Insert Mode.
2. It groups the deletion AND the replacement into ONE atomic undo unit.
3. Crucially: It empowers the DOT command `.` to repeat the exact same change elsewhere!

Commands:
  cw      : Change to end of word (deletes word & enters insert)
  cW      : Change to end of WORD
  cc / S  : Change entire line (clears line, preserves indentation, enters insert)
  c$ / C  : Change from cursor to end of line
  ct{c}   : Change up till character {c}
  cf{c}   : Change through character {c}
  s       : Substitute single character (delete 1 char & enter insert)
  r{c}    : Replace single character with {c} (STAYS in Normal Mode! Fastest typo fix!)
  R       : Enter Replace mode (overwrites characters one-by-one until you press Esc)

This is the single biggest feature that separates Vim masters from beginners.
Text objects allow you to operate on structured code blocks regardless of where
your cursor is inside that block!

Formula:
  [OPERATOR: d, c, y, v] + [TARGET: u (inner) or a (around)] + [OBJECT]

MODULE 07: COPY (YANK), PASTE (PUT) & THE REGISTER BLACK HOLE
================================================================================
Commands:
  yy / Y  : Yank (copy) current line
  yw      : Yank word
  yu"     : Yank text inside quotes
  ya(     : Yank text around parentheses
  p       : Put (paste) after cursor / line below
  P       : Put (paste) before cursor / line above

--- The Dreaded Trap: "I yanked something, deleted an old line, and my yank is gone!" ---
Why this happens: In Vim, `dd`, `dw`, `cw`, `x` are NOT just deletes—they are CUTS!
They overwrite the default unnamed register `"`.
So when you do `yy` (yanked text A), then `dd` (deleted text B), and press `p`,
it pastes text B!

The 3 Solutions Every Pro Uses:
1. Register "0 (The Yank Register):
   Register `0` ALWAYS holds the last explicitly YANKED text! Deletes never touch it!
   Press: `"0p` to paste your yanked text even after deleting 20 lines!
2. The Black Hole Register `"_`:
   Delete without saving to clipboard: `"_dd` or `"_dw` or `"_cuw`.
   The `_` register is a black hole—it discards the text forever.
3. System Clipboard:
   "+y : Yank to Windows clipboard (Ctrl-C to other apps)
   "+p : Paste from Windows clipboard (Ctrl-V from other apps)
4. Named Registers:
   "ay : Yank into register a
   "ap : Paste from register a (you have registers a through z!)

---> PLAYGROUND 7.1: The "0p Secret ---
1. Place cursor on Line 1 below. Press `yy` to yank it.
2. Move cursor to Line 2. Press `dd` to delete it.
3. If you press `p` now, you would paste the junk line you just deleted!
4. Instead, press `"0p`!
Notice it pastes Line 1 cleanly!

MODULE 08: THE LEGENDARY DOT COMMAND ( . )
================================================================================
The dot `.` key repeats the last change.
The master formula:
  "One keystroke to move, one keystroke to repeat."

Scenario: You need to append a semicolon `;` to the end of 5 lines.
Manual newbie way: Go to end, insert, semicolon, esc, down, go to end... (40 keystrokes)
Vim way:
  On line 1: `A;` `<Esc>`
  On line 2: `e .`  (Colemak: down line + dot!)
  On line 3: `e .`
  On line 4: `e .`

MODULE 09: SEARCH MASTERY & THE cgn TRICK
================================================================================
Commands:
  /pattern<CR> : Search forward
  ?pattern<CR> : Search backward
  j  [n]       : Jump to NEXT search match in your Colemak-DH setup
  J  [N]       : Jump to PREVIOUS search match
  *            : Search for the word currently under your cursor (NO TYPING!)
  #            : Search backward for word under cursor
  <leader>ch   : Clear search highlights (:nohlsearch)

--- The Magical `cgn` Combo ---
What is `cgn`?
`c` = Change, `gn` = Next search match.
It replaces the search match you are currently on, so pressing `.` automatically
jumps to the NEXT match AND replaces it!
This gives you an interactive, selective Find & Replace:
  1. Search for word: `/target<CR>` or press `*` on it.
  2. Press `cgn`, type replacement, press `<Esc>`.
  3. Press `.` to replace the next one, OR press `j` [n] to skip it and find next!

---> PLAYGROUND 9.1: The cgn Dance ---
We want to change `bad_var` to `good_var`, but leave `keep_bad_var` alone:
1. Place cursor on `bad_var` in line 1.
2. Press `*` to highlight it.
3. Press `cgn`, type `good_var`, press `<Esc>`.
4. Press `.` on line 2 to replace it.
5. On line 3, press `j` [n] to SKIP `keep_bad_var`!
6. On line 4, press `.` to replace the last one!

Line 2: int double_bad = bad_var * 2;
Line 3: int preserve_this = keep_bad_var;

MODULE 11: MACROS: RECORD ONCE, REPLAY ACROSS 50 LINES
================================================================================
A macro records your exact sequence of keystrokes and replays them automatically.

Formula:
  qa      : Start recording macro into register 'a' (statusline shows recording @a)
  ...     : Do your editing actions (ALWAYS end in a repeatable position, like next line!)
  q       : Stop recording
  @a      : Play back macro 'a' once
  @@      : Repeat the last executed macro
  10@a    : Execute macro 'a' 10 times in a row!

Golden Rule of Macros:
Always make each macro self-contained: start at column 0 (`^` or `0`) and end
at column 0 on the NEXT line (`e0` or `j0`). That way, running `50@a` works smoothly!

---> PLAYGROUND 11.1: Transform Raw Data into C++ Array ---
Goal: Convert raw numbers into `{ 10, "item" },` format.
1. Put cursor on '1' on line 1 below.
2. Press `qa` to start recording into register a.
3. Press `^` (go to start), press `u` [i], type `{ `, press `<Esc>`.
4. Press `$` (go to end), press `a`, type `, "item" },`, press `<Esc>`.
5. Press `e0` (move to start of next line!).
6. Press `q` to stop recording.
7. Now press `3@a` (or `@a` then `@@` then `@@`)!
Line 1: 10
Line 2: 20
Line 3: 30
Line 4: 40

MODULE 14: SURROUNDING TEXT IN PARENTHESES, BRACKETS & QUOTES
================================================================================
Putting selected text inside ( ), [ ], { }, or " " is one of the most frequent
needs in programming (math expressions, function arguments, string literals).

In your setup, you now have THREE ways to do this, ranging from an effortless
1-keystroke shortcut to powerful normal-mode motions:

METHOD 1: THE 1-KEYSTROKE VISUAL WRAP (Easiest & Fastest!)
  1. Highlight any text in Visual mode: `v` (characterwise) or `V` (linewise).
  2. Press the symbol you want to wrap with:
     ( or )  -> wraps in ( ... )
     [ or ]  -> wraps in [ ... ]
     { or }  -> wraps in { ... }
     "       -> wraps in " ... "
     '       -> wraps in ' ... '
     `       -> wraps in ` ... `
     < or >  -> wraps in < ... >

METHOD 2: NORMAL MODE SURROUND with mini.surround (No Selection Needed!)
  gsa{motion}{char} : Add surrounding around {motion}
    Example: `gsaw)` surrounds the current word in ( )!
    Example: `gsa$"` surrounds from cursor to end of line in " "!
  gsd{char}         : Delete surrounding {char}
    Example: `gsd)` on `(a + b)` deletes the parentheses -> `a + b`!
    Example: `gsd"` on `"hello"` deletes the quotes -> `hello`!
  gsr{old}{new}     : Replace surrounding {old} with {new}
    Example: `gsr)["` replaces `[item]` with `"item"`!
    Example: `gsr)}` replaces `(x)` with `{x}`!

METHOD 3: THE PURE STOCK VIM WAY (Works on any bare server without plugins)
